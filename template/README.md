# template/

This is where the files the kit copies into every project will go: `.claude/` (permissions, hooks, agents, skills, rules), `.github/` (issue templates, CI), a `CLAUDE.md` skeleton and the `docs/` folders.

It stays empty until **Phase 4**: only what has worked on jamly goes in (see [ADR 0001](../docs/decisions/0001-separate-kit-piloted-on-jamly.md)). The planned layout is in [PLAN.md](../docs/PLAN.md#final-layout-of-this-repo).
