# 0004 · Everything in a repo is in English

**Status:** accepted · 2026-10-30

## Context
The first version of this repo was written in Italian. Repos are read by agents, by tools and, eventually, by other people; the apps themselves may be in any language.

## Decision
Code, docs, decisions, issue and PR text, and commit messages are in English, in this repo and in every project that uses the kit. The language of an app's UI is a product decision of that app.

## Consequences
- The kit's templates and rules are written in English and tell agents to write in English.
- Conversation with me can stay in Italian; what lands in the repo doesn't.
